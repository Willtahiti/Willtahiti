# Modèle Bento Slides — Société

Fichier autonome (`Modele_Bento_Societe.bento.html`) : ouvrez-le directement dans
un navigateur, aucune installation requise. C'est l'éditeur Bento Slides et
votre deck en un seul fichier.

## Personnaliser

1. Ouvrez `Modele_Bento_Societe.bento.html` dans un navigateur.
2. Menu **?** (ou **À propos**) → **Document properties** : renseignez le nom
   de votre société dans le champ `company` — il se propage automatiquement
   partout où `{{company}}` apparaît (page de garde, en-têtes, slide de
   contact...).
3. Remplacez les textes placeholder (mission, services, chiffres, équipe,
   contact) directement sur le canevas.
4. Couleur d'accent / fond / police : panneau de droite → réglages du thème,
   ou éditez `theme.accent` dans le JSON (`#2F5FDE` par défaut).
5. **Sauvegarder** : le bouton Save (menu déroulant) permet d'enregistrer une
   copie, un nouveau deck, ou de ré-exporter comme template pour vos
   collègues.

## Contenu du modèle

9 slides : page de garde, sommaire, mission (avec un état caché "en savoir
plus" en démonstration du drill-down), services (tableau comparatif),
chiffres clés (compteurs animés + graphique), équipe, transition de section,
contact. Un chrome de marque (kicker + numéro de page) morphe d'une slide à
l'autre, plus 3 layouts réutilisables (Titre, Titre + contenu, Section) pour
créer de nouvelles slides déjà à vos couleurs.

Le fichier est marqué comme **template** : à l'ouverture, l'application lui
attribue automatiquement une nouvelle identité de document, donc vous pouvez
le dupliquer autant de fois que nécessaire sans collision.
